# AstrWeChat 1.2.0

发布日期：2026-09-05

Bridge 概览升级为日志驱动的 Work 面板，并完善私聊定位、群聊权限和安装构建流程。

## 新增

- 新增 Work 面板，根据实际日志展示消息接收、AstrBot 推送、发送队列和 UIA 发送过程。
- 新增“以微信ID查找联系人”开关，私聊回复可优先通过微信 ID 定位会话。
- 新增全局会话白名单/黑名单，支持扫描群聊、搜索多选和手动输入会话 ID。
- 新增 `npm run build-installer` 命令，同时保留 `build-installer.bat`。

## 改进

- 工作流条目支持弹入、停留和收拢弹走，新步骤会追加到已有步骤下方。
- Work 面板保持与运行状态卡片等高，消息较多时在面板内部滚动，不再引起页面跳动。
- 群聊回复文案统一显示为“响应@”。
- 会话过滤规则保存后热更新，队列中的回复发送前也会重新校验。
- 兼容 v1.1.x 的主动回复白名单配置，并在保存时提示权限变化。

## 修复

- 修复 Windows PowerShell 5.1 读取中文 `package.json` 失败的问题。
- 修复 Electron 43 运行时未下载时安装脚本误报缺失的问题。
- 构建脚本支持复用本机 Electron 和 ffmpeg 二进制，减少 GitHub 下载超时影响。
- 修复依赖目录不完整时误跳过安装的问题。
