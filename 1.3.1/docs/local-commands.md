# 使用 AstrWeChat 1.3.1 本地指令

本地指令由 AstrWeChat 直接处理，不进入 AstrBot/KouriChat、普通消息合并缓冲或群聊上下文。

> 需要 Bridge 正在运行且微信消息推送可用；机器人服务端可以暂时离线。当前沿用 SSE 的自发消息过滤，请使用另一个微信账号发送指令。
>
> 功能已完成自动化回归和模拟设置页交互测试，尚未进行真实微信账号端到端附件发送验收，也未重新生成安装包。

## 配置管理员

1. 用另一个微信账号私聊机器人或在允许回复的群聊发送 `#uid`。
2. 复制返回的完整 ID，例如 `AW-0123456789ABCDEF01234567`。
3. 打开侧边栏“AW配置”，在管理员栏中添加 ID，可填写备注。
4. 点击“保存配置”。保存后立即生效，不需要重启 Bridge。

UID 绑定真实发送者微信标识，不按昵称或群聊 ID 判断；同一用户换群、私聊和 Bridge 重启后保持一致。缺少真实发送者标识时拒绝鉴权。

支持最多 100 个全局管理员。群聊黑白名单优先，本地指令不会绕过会话过滤。

## 指令

指令不区分大小写。`#aw` 只显示菜单，其他功能使用独立命令：`#uid`、`#status`、`#stop`、`#start`、`#ac`。

| 指令 | 权限 | 作用 |
| --- | --- | --- |
| `#aw` | 所有人 | 显示当前权限可用菜单和实际程序版本 |
| `#uid` | 所有人 | 显示自己的稳定 UID 和权限 |
| `#status` | 管理员 | 显示连接状态及当前会话设置 |
| `#stop` | 管理员 | 暂停当前会话向机器人服务端转发 |
| `#start` | 管理员 | 恢复当前会话后续消息转发 |
| `#ac` | 管理员、仅群聊 | 回显当前群最近 10 条已缓存消息 |
| `#ac <回溯码>` | 管理员、仅原群 | 直接发送编号对应的已缓存附件 |

状态消息没有空行：

```text
#status
消息推送：正常
AstrBot：已连接
当前会话：测试群
回复模式：仅提及
```

暂停时“消息推送”显示“已暂停”。选择 KouriChat 时显示 KouriChat。私聊回复模式显示“私聊”。

已识别的 AW 本地命令若参数错误或无权限，仍在本地处理，不回退转发。`#aw` 后带子命令会提示改用独立命令。非纯文字消息不能通过文件名或卡片标题执行命令。

## 暂停和恢复

- `#stop` 只影响当前群聊或私聊，不影响其他会话。
- 暂停后继续监听并缓存允许群聊的消息，本地指令仍可使用。
- 暂停会清理当前会话未发送缓冲、待关联附件和群聊上下文。
- 异步媒体和计时器携带转发代次，暂停前的结果不会在恢复后补发。
- `#start` 不补发暂停期间消息。
- 已交给机器人服务端的请求无法撤销，其正在生成或排队的回复仍可能发送。
- 暂停状态仅保存在内存中，Bridge 重启后默认恢复转发。

## 回显和附件

```text
Anti-Callback
用户A：123123
用户B：[文件] 项目资料.zip ｜ 回溯码：F7A2B901
用户C：[图片] ｜ 回溯码：D31C8A04
```

回溯码显示在附件消息同一行右侧。发送 `#ac F7A2B901` 获取附件。

附件统一使用“回溯码”，不提供其他称呼选项。

- 最近消息按时间从旧到新，不足 10 条时显示已有内容。
- `#aw`、`#uid`、`#status`、`#stop`、`#start`、`#ac` 等本地指令不会显示在回溯结果中，也不计入最近 10 条；本地回复、机器人自发消息和撤回系统提示同样不计入。
- 已监听到的原文不会被撤回提示覆盖；启动前或断线期间未读到的消息不能保证恢复。
- 尝试缓存文件、图片、表情、视频和语音。语音以音频文件回发，不是微信原生语音气泡。
- 首次配置管理员前，不为此功能缓存群聊历史和附件。
- 附件只有复制到专用缓存成功后才显示可用编号。未下载、超限、校验失败或不能精确定位时不发布编号。
- 匹配附件要求原消息 ID；服务器 ID 冲突时不会回退到文件名、时间或邻近消息。
- 编号绑定原群和原消息，其他群不能使用。
- 附件有效期独立于最近 10 条；消息被挤出列表后，编号在有效期内仍可使用。
- 超长消息会截断并标注；长回显按完整消息行分段，回溯码不会与对应消息拆开。

## 缓存限制

| 配置 | 默认值 | 范围 |
| --- | --- | --- |
| 附件有效期 | 24 小时 | 1–168 小时 |
| 单个附件上限 | 100 MB | 1–1024 MB |
| 附件缓存总上限 | 512 MB | 1–4096 MB |

专用附件缓存位于 Bridge 用户数据目录下的 `aw-ac-cache`。正常关闭时清理；异常退出遗留内容在下次准备缓存时清理。该目录已排除 Git 和安装包资源。

群聊文本历史仅在内存中保存，最多 200 个群、每群 10 条、最长 24 小时。Bridge 重启后，历史、回溯码映射和暂停状态均不保留。

## 验证

在 `1.3.1` 目录运行：

```powershell
npm run test:bridge
npm run typecheck
npm run typecheck:bridge
```

当前验证结果：64 项 Node 测试、40 项 Python 测试通过；两项 TypeScript 类型检查通过。模拟设置页已验证管理员格式、添加、去重、备注、回溯码展示、缓存限制、保存恢复、移除授权和窄窗口布局。

真实微信仍需在专用测试群手动验收：查询 UID、授权、回显文本和附件、撤回后获取、跨群拒绝以及暂停/恢复。
